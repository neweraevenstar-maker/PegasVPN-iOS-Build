PegasVPN Support

Operated by VIM VITAE LIMITED, Hong Kong.

Contact

Email: info@vimvitae.net. Include your app version and iOS version. Never send passwords, one-time codes or VPN private keys.

Connect

Open PegasVPN, select an available server, tap Start and approve the iOS VPN permission. If connection fails, check your internet connection and subscription status.

Sign in

Sign in with Apple or request a six-digit code by email. Check spam if the code does not arrive.

Subscriptions

Manage or cancel via Apple Subscriptions. Restore eligible purchases inside PegasVPN. Request refunds through Apple.

Delete account

Open Account, choose Delete account and confirm. This revokes VPN access but does not cancel your Apple subscription.

Privacy requests

Email info@vimvitae.net for access, correction or deletion requests. We may need to verify account ownership.
