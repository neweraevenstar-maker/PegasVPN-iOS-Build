# OneTap VPN v0.1

SwiftUI prototype of the main iOS screen.

Current functionality:
- START / STOP UI state
- connection status
- connection timer
- Fastest Server row

Important: v0.1 does NOT create a real VPN tunnel yet. The next milestone is NetworkExtension + Packet Tunnel/WireGuard and a real VPN server.

To run this version, create an iOS App project named `PegasVPN` in Xcode and replace the generated Swift files with the files in `PegasVPN/`.
